## Discovery Guardrails

- GitHub topics must include one allowlisted bio topic, for example `bioinformatics`, `biomedical`, `genomics`, `single-cell`, `proteomics`, `drug-discovery`.
- Stars must be above the configured threshold, default `DISCOVERY_MIN_STARS=10`.
- Repository description plus README must contain at least one bio term and one project/tool term.
- Forks, archived repositories, and repos already present in `data/catalog.json` are excluded.
